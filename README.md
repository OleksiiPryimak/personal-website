# 🌐 Personal Website — Oleksii Pryimak

A personal website and portfolio built from scratch using clean web technologies (**HTML5, CSS3, Vanilla JavaScript**). The site serves as a digital professional business card, combining a modern visual style with interactive effects, responsive image galleries, and smooth animations.

---

## 🛠️ Tech Stack

* **HTML5** — Semantic, SEO-optimized, and accessible structure.
* **CSS3** — Custom styling, Flexbox, CSS Grid, Responsive Web Design (RWD), and smooth 3D transitions.
* **Vanilla JavaScript (ES6+)** — Interactive logic, canvas animations, custom Lightbox modal with arrow navigation, and dynamic UI elements without external frameworks.

---

## ✨ Main Structure & Features

1. **Hero Section**
   * **Animated Particle Background:** Interactive cosmic particle effect rendered on a HTML5 Canvas element.
   * **SEO-Friendly Typewriter Effect:** Visual typing effect for roles and specializations without hiding static HTML content from search engine crawlers.
   * **Interactive Header & Navigation:** Smooth hover effects and micro-interactions.

2. **About Me Section**
   * A concise summary of professional profile, goals, and technical passions.
   * Elegant and readable typography tailored for all device sizes.

3. **Skills Section**
   * Visual presentation of the technology stack (Python, web technologies, graphics tools).
   * Interactive cards with subtle hover animations triggered on scroll.

4. **Projects / Portfolio & Dedicated Galleries**
   * Featured interactive 3D carousel for main projects on the home page.
   * **Standalone Galleries (`art.html` & `graphics.html`):** Dedicated subpages featuring a 3-column grid layout with an interactive, keyboard-supported Lightbox image viewer with next/previous navigation.

5. **Contact Section**
   * Contact details and links to social media profiles (GitHub, LinkedIn) with polished micro-interactions and icon animations.

---

## 🎨 Visual Effects & Animations

* **Smooth Scroll:** Comfortable navigation between page sections.
* **Reveal on Scroll Animations:** Elements smoothly fade/slide into view as the user scrolls.
* **Responsive Web Design (RWD):** Fluid layout ensuring seamless display across mobile phones, tablets, and high-resolution desktop displays.
* **Lightweight & Fast:** Built without heavy external JavaScript libraries or CSS frameworks to guarantee maximum performance and high Google PageSpeed / Lighthouse scores.
