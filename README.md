# 🌐 Personal Website — Oleksii Pryimak

A personal website and portfolio built from scratch using clean web technologies (**HTML5, CSS3, Vanilla JavaScript**). The site serves as a digital professional business card, combining a modern visual style with interactive effects and smooth animations.

---

## 🛠️ Tech Stack

* **HTML5** — Semantic and accessible structure.
* **CSS3** — Custom styling, Flexbox/Grid, Responsive Web Design (RWD), and smooth transitions.
* **Vanilla JavaScript (ES6+)** — Interactive logic, canvas animations, and dynamic effects without using external frameworks.

---

## ✨ Main Structure & Features

1. **Hero Section**
   * **Animated Particle Background:** Interactive background effect (particles) simulating cosmic stars rendered on a Canvas element.
   * **Typewriter Effect:** Dynamically typed and changing text displaying roles and specializations.
   * **Interactive Header & Buttons:** Smooth hover effects and quick navigation to the rest of the site.

2. **About Me Section**
   * A concise summary of professional profile, goals, and programming passions.
   * Elegant and clean text layout tailored for any device.

3. **Skills Section**
   * Visual presentation of the technology stack (programming languages, tools, frameworks).
   * Animated cards or progress bars that trigger on scroll.

4. **Projects / Portfolio Section**
   * A gallery of featured projects with descriptions, tech stacks used, and external links.
   * Hover effects highlighting project card details.

5. **Contact Section**
   * Contact form for direct messaging.
   * Links to social media profiles (GitHub, LinkedIn) with polished micro-interactions and icon animations.

---

## 🎨 Visual Effects & Animations

* **Smooth Scroll:** Comfortable navigation between page sections.
* **Reveal on Scroll Animations:** Elements smoothly appear on the screen as you scroll down.
* **Responsive Web Design (Mobile-First / RWD):** Perfect alignment across smartphones, tablets, and high-resolution monitors.
* **Lightweight & Fast:** Built without heavy external libraries to ensure lightning-fast load times.
